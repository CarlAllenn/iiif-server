# iiif-server (working name)

A modern IIIF Image API server: **3.0 and 2.1, level 2 plus the complete optional feature table**, pure Rust, one static binary, one contained C library (OpenJPEG), stateless, scope-frozen at 1.0.

**Status: design phase.** No code yet. The founding document is [docs/design-spec.md](docs/design-spec.md) — it is the decided spec from the 2026-07-26 scoping session and is self-contained: tooling standup and the build proceed from it, starting at milestone M0 (skeleton + the two de-risking spikes).

The repo name is a placeholder; product naming, org, and domain are deliberately deferred to the launch milestone. Nothing gets published to crates.io, Docker Hub, or any registry until then.
